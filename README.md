## Descrição

Programa desenvolvido em Java para calcular o índice de Massa Corporal (IMC) e realizar sua classificação de acordo com o gênero informado.

O programa recebe o nome, gênero, altura e peso do usuário, calcula o IMC e apresenta sua classificação.
